# Установщик модов Valheim

Готовый установщик набора модов для обычной игры и выделенного сервера Valheim.

## Возможности

- установка 15 игровых модов на Windows;
- установка 11 совместимых модов на выделенный сервер;
- русские названия и версии модов;
- выборочное удаление, удаление всех модов или полная очистка компонентов;
- резервное копирование заменяемых и удаляемых файлов;
- автоматический поиск папок Valheim в библиотеках Steam;
- безопасная проверка и установка обновлений;
- отдельный установщик для Steam Deck/Linux.

## Скачать

Актуальные файлы находятся в разделе [Releases](https://github.com/FULLMEGO/VALHEIM/releases/latest).

Для Windows нужен только `Valheim-Mods-Installer-Windows.exe`. Для Steam Deck/Linux скачайте и полностью распакуйте `Valheim-Mods-Installer-Steam-Deck.zip`.

Перед установкой или удалением закройте игру и выделенный сервер. Windows может показать предупреждение SmartScreen, потому что самостоятельно собранный файл не подписан платным сертификатом издателя.

## Обновления

Windows-установщик получает номер новой версии и SHA-256 из файла `update.txt`. Загруженный файл устанавливается только после успешной проверки контрольной суммы.
