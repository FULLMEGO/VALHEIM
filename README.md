# VMod

Современный менеджер модов Valheim для обычной игры и выделенного сервера.

## Возможности VMod 2.0

- один самодостаточный `VMod.exe` для Windows и запуска через Proton на Steam Deck;
- 15 встроенных игровых модов с русскими названиями;
- 11 совместимых модов для выделенного сервера;
- счётчики установленных, отключённых и новых модов;
- включение, временное отключение и выборочное или полное удаление модов;
- перетаскивание Thunderstore ZIP прямо в окно — архив сохраняется в библиотеке VMod;
- установка новых модов отдельно в игру или на сервер;
- запуск Valheim и выделенного сервера;
- автоматическое определение библиотек Steam, включая пути Steam Deck через Proton;
- самостоятельное обновление по кнопке с обязательной проверкой SHA-256;
- резервные копии заменяемых и удаляемых файлов.

## Скачать

Актуальный файл находится в разделе [Releases](https://github.com/FULLMEGO/VALHEIM/releases/latest).

Для Windows запустите `VMod.exe`. При первом использовании укажите папку Valheim, если VMod не нашёл её автоматически.

## Steam Deck

1. Перейдите в режим рабочего стола.
2. Скачайте тот же `VMod.exe` из последнего релиза.
3. В Steam выберите «Добавить стороннюю игру» и укажите `VMod.exe`.
4. В свойствах добавленной игры включите принудительное использование Proton Experimental.
5. Запустите VMod из Steam. Программа ищет игру в стандартных папках Deck через диск `Z:` Proton; при необходимости путь можно выбрать вручную.

Нативной Linux-сборки интерфейса нет: на Steam Deck приложение запускается через Proton. Функциональность подготовлена для этого режима, но окончательная проверка всё равно должна выполняться на самом устройстве.

## Безопасность

VMod работает только с выбранными папками Valheim и собственной библиотекой `%LocalAppData%\\VMod`. Перед заменой или удалением файлов создаются резервные копии в `BepInEx\\VMod`. Загруженное обновление устанавливается только после совпадения SHA-256 с опубликованным манифестом.

Windows может показать SmartScreen, поскольку файл собран самостоятельно и не подписан платным сертификатом издателя.
